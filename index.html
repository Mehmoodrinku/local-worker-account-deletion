Local Worker — Account Deletion

This page is for users of the Local Worker app who want to request deletion of their account and associated personal data.

How to request deletion

Enter the mobile number used in Local Worker and your Worker ID or Customer ID if available. Submit the request using the button below.

What happens next?

Your request will be reviewed and the account/data associated with the request will be processed for deletion. Data that must be retained for legitimate legal, security, fraud-prevention, or regulatory reasons may be retained as required.

Data covered

The request may cover account/profile information associated with the Local Worker account, including mobile number, Worker ID or Customer ID, worker profile information, location information associated with a worker profile, and other account-related personal data.
